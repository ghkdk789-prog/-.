# Архив Разбитой души

Мобильное PWA-приложение на русском языке для личной структуры серии книг без заранее созданного лора или выдуманных записей.

## Публикация

GitHub Pages готов через workflow `.github/workflows/pages.yml`. После публикации рабочая ссылка будет иметь вид:

`https://<ваш-github-логин>.github.io/<имя-репозитория>/`

Для текущего репозитория без настроенного remote точный логин GitHub определить невозможно. Когда `origin` будет добавлен, команду ниже можно использовать для вывода готовой ссылки:

```bash
npm run pages:url
```

## Локально

```bash
npm run start
```
